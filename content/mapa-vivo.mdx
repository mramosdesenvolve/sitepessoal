O **Mapa Vivo** nasceu de uma frustração concreta: currículos são redes, mas os documentos que os descrevem são listas. O software permite que educadores desenhem currículos como grafos navegáveis — conceitos como nós, práticas e recursos como conexões, percursos como caminhadas possíveis.

## Como funciona

1. O educador cria **nós de conceito** e os conecta livremente — não há hierarquia obrigatória, não há "pré-requisito" como categoria fundante.
2. Cada nó recebe **práticas e recursos**: uma oficina, um texto, um problema, um vídeo.
3. Estudantes navegam o grafo escolhendo percursos, e o sistema registra a caminhada — não como vigilância, mas como memória do trajeto, matéria-prima para a avaliação narrativa.

## O experimento com IA

A versão atual inclui um experimento de sugestão de conexões por embeddings: a máquina propõe arestas entre conceitos que parecem próximos, **e o educador decide**. A divisão de trabalho é deliberada — a IA amplia o campo de visão, o humano mantém a autoria do currículo. É a mesma posição defendida no artigo sobre IA na formação docente.

## Software como pesquisa

O código é aberto porque o projeto é também um estudo de caso de *software como cultura*: cada decisão de interface carrega uma teoria de currículo. Um botão de "pré-requisito" ensinaria linearidade; sua ausência ensina rede.
